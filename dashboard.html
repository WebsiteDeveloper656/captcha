📚 CAPTCHA API Documentation

Use your API key to generate and verify CAPTCHAs from your website or application.

🌐 Base URL

{{ request.url_root }}

🔑 Authentication

Send your API key in the X-API-Key header. 

X-API-Key: YOUR_API_KEY

1️⃣ Create CAPTCHA

Creates a new CAPTCHA. 

POST /captcha/create

Headers:

X-API-Key: YOUR_API_KEY

Response

{
    "success": true,
    "captcha_id": "YOUR_CAPTCHA_ID",
    "image_url": "/captcha/image/YOUR_CAPTCHA_ID",
    "expires_in": 120
}

2️⃣ Get CAPTCHA Image

GET /captcha/image/<captcha_id>

Create CAPTCHA से मिले captcha_id को URL में use करें।

3️⃣ Verify CAPTCHA

POST /captcha/verify

Headers:

X-API-Key: YOUR_API_KEY
Content-Type: application/json

Request Body

{
    "captcha_id": "CAPTCHA_ID",
    "answer": "ABC123"
}

Successful Response

{
    "success": true,
    "verified": true,
    "message": "CAPTCHA verified successfully"
}

Incorrect CAPTCHA

{
    "success": true,
    "verified": false,
    "message": "Incorrect CAPTCHA"
}

⏱ CAPTCHA Expiration

Each CAPTCHA expires after 120 seconds.

❌ Common Errors

400  JSON body required
401  Invalid API key
403  Unauthorized CAPTCHA
410  CAPTCHA expired / already used
429  Usage limit exceeded
